# PvP Scroutopia Edit

An Edit of the [PvP Scroutopia](https://modrinth.com/resourcepack/pvp-) Texture Pack by [Scroutop](https://modrinth.com/user/Scroutop).

Polytone is optional for colored XP text.

### I Changed:
- UI
- Items (other than the Apple)
- Effect Particles
- End Crystal
- Totem Sound
- XP Bar Color
